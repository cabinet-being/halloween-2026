# Naming Convention

## Resource Prefixes

- `ACT_` — actor prefabs.
- `TPL_` — template prefabs.
- `ENV_` — environment elements.
- `HBLE_` — holdable objects.
- `UI_` — UI prefabs.
- `PROP_` — scene props.
- `MAT_` — materials.
- `SCN_` — scenes.

## Scripts

- Class names: `PascalCase`; match the script filename.
- Private fields: `_camelCase`.
- Public properties: `PascalCase`.
- Methods: verbs or verb phrases in `PascalCase`.

## Documentation

- Main project document: `README.md`.
- Topic documents: `Docs/<Topic>.md`.
- Keep each topic document focused on one aspect of the project.
